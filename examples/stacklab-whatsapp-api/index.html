01 Origem e permissão

Antes de pensar no disparo

Não basta ter o número.
Entenda a permissão.

Registre quando, onde e para qual finalidade a pessoa compartilhou o contato.

Uma base confiável responde a três perguntasCONTATO → CONTEXTO
Onde?Qual foi a origem do contato?
Quando?Em que momento a preferência foi registrada?
Para quê?Que tipo de mensagem a pessoa espera?
Guarde a preferência junto do contatoUma compra antiga não autoriza qualquer campanha futura.
Se alguém pedir para parar, atualize a preferência em todos os sistemas que enviam.
