# Instagram Carousel Skill

Create clear, brand-led Instagram carousels with concise storytelling, considered visual design, editable HTML, and export-ready images. The included StackLab example demonstrates one localized five-slide application.

## Install

Install this skill with the `skills` CLI:

```sh
npx skills add magdielcardoso/instagram-carousel-skill --skill instagram-carousel
```

Invoke `$instagram-carousel` and provide the content, audience, slide count, and brand direction. Link the site, repository, or attachments that contain those details when available.

## Design guidance

The skill routes by objective: educational/informational, product or service promotion, or event promotion. Shared guidance covers contrast, composition, type hierarchy, spacing, corner treatments, iconography, purposeful backgrounds, distinct art direction between carousels, and honest retention loops across slides. Persuasive routes also use an [audience-value-proof framework](skills/instagram-carousel/references/audience-value-and-proof.md), kept separate from the editorial approach so campaign techniques do not turn informational content into advertising. The adaptation includes [source attribution and full usage terms](skills/instagram-carousel/references/revenue-centric-design-license.txt), including its restricted-use boundary.

## Included examples

These paired Portuguese-language StackLab examples demonstrate two distinct directions for informational carousels: a conversational editorial treatment for messaging practices, and a technical blueprint for explaining the API flow. Both keep the brand recognizable while changing composition, background language, and visual pacing. Their copy raises and answers content-grounded questions without manufacturing suspense or turning education into a sales funnel. Both use editable HTML/CSS, local Phosphor icons, Anton display titles, and PNG export at 1080 × 1350 px.

## Português (Brasil)

Crie carrosséis claros e alinhados à marca, com narrativa concisa, design intencional, HTML editável e imagens prontas para exportar. O exemplo StackLab incluso demonstra uma aplicação localizada de cinco telas.

### Instalação

Instale esta skill pelo CLI `skills`:

```sh
npx skills add magdielcardoso/instagram-carousel-skill --skill instagram-carousel
```

Invoque `$instagram-carousel` e informe o conteúdo, o público, a quantidade de telas e a direção da marca. Quando esses detalhes estiverem em um site, repositório ou anexos, inclua o link ou os arquivos no pedido.

### Orientações de design

A skill escolhe a direção pelo objetivo: conteúdo educativo/informativo, divulgação de produto ou serviço, ou divulgação de evento. As orientações gerais cobrem contraste, composição, hierarquia tipográfica, espaçamento, cantos, ícones, fundos intencionais, direções visuais distintas entre carrosséis e loops de retenção honestos entre os slides. As direções persuasivas também usam um [framework de público, valor e comprovação](skills/instagram-carousel/references/audience-value-and-proof.pt-BR.md), separado da abordagem editorial para que técnicas de campanha não transformem conteúdo informativo em anúncio. A adaptação inclui [atribuição e termos completos de uso da fonte](skills/instagram-carousel/references/revenue-centric-design-license.txt), com seu limite de aplicação.

### Exemplos incluídos

Estes exemplos StackLab em português mostram duas direções distintas para carrosséis informativos: um tratamento editorial de conversa para boas práticas de mensagens e um blueprint técnico para explicar o fluxo da API. Ambos mantêm a marca reconhecível, mas variam composição, linguagem de fundo e ritmo visual. A copy levanta e responde perguntas ligadas ao conteúdo, sem suspense artificial nem conversão do material educativo em funil de vendas. Os dois usam HTML/CSS editável, ícones Phosphor locais, títulos Anton e exportação PNG em 1080 × 1350 px.
